A program that writes one plan to /output/entry.txt: the plan an AI agent would follow to turn $100 into the most money in 30 days — selling email-deliverability fix packs to cold-email agencies, generated by public DNS scans, paid in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
